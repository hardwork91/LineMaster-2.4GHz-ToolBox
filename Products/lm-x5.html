Key Features

5-Channel PWM Output

Full 5-channel control for throttle, flaps, retracts and more.

RGB LED Status Indicator

Multicolor LED for clear visual feedback on binding, signal and operation status.

Manual Throttle Input

Dedicated input pin for manual throttle control devices.

Easy Binding

Dedicated bind button for quick and simple pairing with any LineMaster handle.
